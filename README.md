3. Troubleshooting (Dificuldades Encontradas)
Problema 1

Ao pesquisar "IBEX 450", algumas respostas traziam informações da versão internacional chamada "450MT".

Solução:
Utilizei o prompt:

"Considere apenas a versão destinada ao mercado brasileiro."

Problema 2

Alguns sites apresentavam preços diferentes.

Solução:
Cruzei informações de várias fontes para identificar os valores mais recentes divulgados pela marca.

Problema 3

Havia opiniões muito divergentes sobre a qualidade da moto.

Solução:
Separei fatos técnicos de opiniões de usuários, utilizando fontes oficiais e discussões de proprietários para obter uma visão equilibrada.
